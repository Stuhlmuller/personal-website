I added Tailscale ACL rules to restrict the hosted Renovate instance to only reach the Harbor registry relay, preventing it from accessing other services on the homelab network.

## How the Change Works

I extended `scripts/config/tailscale-policy.json` with two new tag-based ACL entries. First, I mapped the `homelab-ci-renovate` and `homelab-harbor-registry` tags to the `autogroup:admin` group, ensuring both endpoints are managed under the same admin scope. Second, I added an explicit allow rule that permits TCP port 443 traffic from the Renovate tag to the Harbor registry tag. I also added a deny rule that explicitly blocks the Renovate tag from reaching other ports on the Harbor registry, the ingress controller, the Kubernetes operator, the control plane, and NAS services, closing off paths that the broad autogroup mapping might otherwise permit.

## What the Evidence Establishes

The patch adds 32 lines to the policy file without removing any existing rules, confirming this is a layered security addition rather than a replacement. The commit message explicitly states the intent: scoping hosted Renovate to the Harbor relay. The deny list is particularly telling—it blocks DNS (port 53), HTTP (port 80), the ingress controller, the k8s operator API, the control plane API server, and NAS NFS access. This shows a deliberate principle of least privilege: Renovate only needs to pull images from Harbor over HTTPS, nothing else.

## Where the Design Transfers

This pattern of tag-to-tag ACLs with explicit deny rules can be applied to any CI process that needs to interact with a single registry while being isolated from the rest of the network. A team running GitLab CI or GitHub Actions in a Tailscale-protected environment could use the same approach: create a dedicated tag for the CI runner, map it to a restricted group, allow only the required registry endpoint, and deny everything else. The key is maintaining an explicit deny list that grows as the service's requirements change, rather than relying on implicit allow rules that could expand access unintentionally.
