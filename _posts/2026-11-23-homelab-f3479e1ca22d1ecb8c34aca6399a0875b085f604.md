A maintenance commit removed the Codeberg chart source allowance from the Argo CD configuration, reducing the set of external Helm repositories the cluster trusts.

## Commit context

The push contains a single commit titled "chore(argocd): retire the Codeberg chart source allowance (#2142)". The change summary reports no visible file diffs and one withheld file, which is consistent with a small configuration removal in the Argo CD source repository definitions.

## Likely change

Based on the commit message, the change removes a `Repository` or `ApplicationSet` reference that pointed to a Codeberg-hosted Helm chart repository. This reduces the attack surface by eliminating an external chart source that is no longer used or vetted.

## Verification approach

After the change, confirm that Argo CD no longer lists the Codeberg repository in its source repositories UI or CLI output. Validate that any Applications or ApplicationSets that previously consumed charts from that source have been migrated to an approved registry or removed.

## Platform engineering note

Teams managing multi‑tenant GitOps clusters can adopt the same practice: periodically audit configured Helm repositories and retire any that are unused, unmaintained, or not covered by supply‑chain policy. The removal is a low‑risk, high‑confidence change when no workloads depend on the source.
