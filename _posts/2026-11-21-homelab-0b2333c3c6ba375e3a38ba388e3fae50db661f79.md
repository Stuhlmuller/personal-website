## Platform engineering: documentation scoping and transferable pattern

Consolidating docs inside Spec Kit reduces drift between app directories and the documentation layer. Teams that run GitOps homelabs or platform repos can apply the same cleanup by identifying README files that duplicate Spec Kit content, deleting them, and updating any stack or agent references that pointed at them. The change keeps operational knowledge in a single discoverable location instead of scattering it under every app folder.
