The latest main push adds a single line to the `IaC/.terragrunt-filters` file, telling Terragrunt to ignore the Terragrunt catalog directory during discovery, which prevents accidental inclusion of catalog resources in IaC runs.

## Add exclusion rule to filters file

I added the pattern `!./terragrunt-catalog/**` to the `IaC/.terragrunt-filters` file. This tells Terragrunt to skip any path under the catalog folder when it builds its discovery list, keeping the discovery scope focused on actual Terragrunt configurations.

## Why exclude the catalog

The Terragrunt catalog contains generated snippets and helper files that are not meant to be applied directly. Including them in discovery can cause unexpected runs or resource conflicts. By filtering them out, the discovery step becomes faster and safer, and operators avoid accidental `apply` of catalog entries.

## Verification and next steps

I will run the standard Terragrunt discovery command in a test environment to confirm that the catalog path is no longer listed. The change is isolated to the filters file, so no other workflows are affected. Other teams can apply the same pattern to any internal directories they wish to keep out of discovery.
