The main branch added a commit that introduces a dedicated `argocd` scope to the Harbor mirror workflow, enabling independent publication and verification of the reviewed Argo CD v3.4.14 digest without requiring a full catalog run.

## New argocd scope in harbor-mirror.yml

The workflow file now accepts `argocd` as an `image_scope` option, and the case statement routes it to a new `mirror-argocd` command. This isolates the Argo CD patch publication from the broader `all` or `fleet` scopes, letting us verify the exact v3.4.14 manifest and complete an authenticated Harbor pull on its own.

## Documentation and policy updates

docs/harbor-image-mirroring.md was extended with an `Argo CD patch publication scope` section that documents the new scope and its purpose. The policy files (`policy/workflows.rego` and `policy/workflows_test.rego`) were updated to include the `argocd` case, keeping the policy enforcement consistent with the workflow changes.

## Test and script support

scripts/ci/harbor-publish.sh gained a `mirror-argocd` case, and scripts/ci/harbor-publish-test.py now handles an optional `argocd_mirror_manifest` and asserts the new scope appears in the workflow. A new config file, `scripts/config/harbor-argocd-images.json`, provides the manifest structure for the scoped publication.
