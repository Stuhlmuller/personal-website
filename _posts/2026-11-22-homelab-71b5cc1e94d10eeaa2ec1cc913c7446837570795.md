I updated the Harbor Core Dockerfile to include cURL and Expat packages, addressing a security vulnerability in the Photon runtime, and documented the package pinning and verification steps in harbor-oci.md.

## Add cURL and Expat runtime packages to Dockerfile

I modified `builds/harbor-core/Dockerfile` to add cURL and Expat runtime packages, which resolves the reported security issue in the Photon runtime. The change ensures that the base image contains the required dependencies for secure package management and network operations.

## Document package pinning and verification in harbor-oci.md

`openwiki/operations/harbor-oci.md` now states that the Dockerfile pins runtime updates for cURL and Expat, and it advises that the full-image scan must verify the package update before protected publication. This documentation clarifies the expectation for CI validation and prevents regressions.

## Apply fix to vulnerable Photon runtime packages

The commit `fix(harbor): update vulnerable Photon runtime packages (#2088)` incorporates the Dockerfile change and ensures that the Harbor Core image no longer contains the vulnerable runtime components. The updated documentation and CI checks support the fix by confirming package presence and integrity.
